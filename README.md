# Fall of the Iron Curtain — «90x»
Полная конверсия - Hearts of Iron IV. Старт **1 января 1990 года**. Ядро мода - Советский Союз в последние два года своего существования: пустые полки, парад суверенитетов, борьба за Союзный договор и августовский путч, до которого ещё надо дожить.
Это не «HOI4 с новой картой»: 1990-й здесь год управленческого давления, а не подготовки к войне. Фокусы задают курс, решения тушат кризисы, события показывают цену, а ежемесячный пульс неумолимо двигает страну к развязке.
- Поддерживаемая версия игры: **1.19.***
- Язык: русский (вся локализация l_russian)
- Рекомендуемая страна: СССР (букмарк «Новый мир девяностых»)
---
## Что уже играется
### Кризисное ядро 1990 (СССР)
- **13 кризисных шкал** (дефицит, чёрный рынок, партийная дисциплина, влияние реформаторов/консерваторов, КГБ, лояльность и политизация армии, сепаратизм республик, российский вызов, союзный договор, уличное давление, риск ЧП)  живут в ежемесячном скрытом пульсе с дрейфом, историческими гейтами по датам и амбиентными событиями.
- **~75 событий 1990 года**: от «проверить склады, а не отчёты» до декларации РСФСР 12 июня, Кузбасса, объединения Германии и итогов года 28 декабря с пятью вариантами диагноза.
- **71 фокус СССР** и **35+ решений** в 7 категориях (снабжение, партия, силовики, республики, Россия, улица, союзный договор) + timed-миссии.
- Итог года расставляет **seed-флаги для 1991**  прожитый 1990 определяет, каким будет путч.
### Модуль 1991
Исторический костяк: Вильнюс (13 января) → Павловская реформа (22 января) → референдум о Союзе (17 марта) → Ново-Огарёво (23 апреля) → выборы президента РСФСР (12 июня) → **ГКЧП (19 августа)** с детерминированной формулой успеха, читающей накопленное состояние страны → 25 декабря диспетчер финала с **четырьмя эпилогами**: хардлайн, слабая конфедерация, хаотичный распад, упорядоченный распад.
### Экономика (два слоя)
- **Генерик-слой** (готов к расширению на другие страны): ВВП из фабрик, мировая цена нефти с кувейтским шоком авг-1990 - фев-1991, нефтяная выручка, бюджет с «липкими» расходами (растут мгновенно, вниз тают 5%/мес — инерция госаппарата), казна/долг/проценты, деловая уверенность → реальный dynamic_modifier (стабильность, ширпотреб, политвласть). Профицит сначала гасит долг; дефицит сначала ест казну.
- **Советский плановый слой**: «план против реальности» и «пушки против масла». Пятилетний план как бумажное обещание, выполнение плана, перекос военки  всё фидбеком в кризисные шкалы. Твёрдая валюта копится с нефтяного экспорта и тратится через решения: зерно, ширпотреб, западные технологии, пересмотр плана Госпланом (с расплатой за приписки).
- Окна экономики в интерфейсе (генерик + советское) — живые переменные прямо на экране.
### Организация Варшавского договора
Фракция с целями (faction goals из 1.19), принудительным членством шести стран Восточной Европы и запретом на самостоятельные альянсы — пока блок ещё держится.
### Прочее
- **Дерево США** — 51 фокус с полными наградами и русской локализацией.
- **Система законов**  16 слотов, 86 вариантов, пресеты по странам, ежемесячный дрейф законов СССР.
- Мини-ветки (Летов, НКР).
- Панель **«Кремль»**  единая мастер-панель управления СССР (в разработке, сейчас этап 0: кнопка в топбаре + каркас окна; сюда поэтапно переедут экономика, кризисная сводка и решения).

```
90x/
├── events/
│   ├── FOTIC_SOV_1990.txt        # кризисное ядро 1990
│   ├── FOTIC_SOV_1991.txt        # модуль 1991 (Вильнюс → ГКЧП → эпилоги)
│   ├── FOTIC_Economy.txt         # генерик-экономика (пульс .100)
│   └── FOTIC_SOV_Economy.txt     # советский плановый слой
├── common/
│   ├── on_actions/               # три подсистемы = три отдельных файла хуков
│   ├── scripted_effects/         # FOTIC_*_effects: клампы, пересчёт модификаторов
│   ├── decisions/                # решения кризиса + экономики
│   ├── ideas/                    # духи, министры, законы (FOTIC_global_laws)
│   ├── national_focus/           # soviet / usa / generic / NKR / Letov
│   └── scripted_guis/            # окна экономики, панель «Кремль»
├── interface/                    # .gui + .gfx (арт конструкторов техники — не трогать)
├── localisation/russian/         # вся лока, только UTF-8 with BOM
├── map/                          # своя карта, 997 стейтов (1..997 без дыр)
└── docs/                         # авторские доки и план (в git не попадает)
```
### Нейминг
- `fotic_<domain>_*` — генерик-мир (экономика и будущие системы других стран)
- `fotic_sov_*` — 13 кризисных шкал СССР
- `fotic_sov_econ_*` — советский плановый слой
- `fotic_1991_*` — seed-флаги, передающие состояние из 1990 в 1991
- `fotic_chi_econ_*` / `fotic_usa_econ_*` — зарезервировано под будущие слои

## Правила разработки (выстраданы практикой)
1. **Три подсистемы не смешивать**: кризис-пульс, генерик-экономика и плановый слой живут в отдельных файлах on_actions/событий/эффектов. Инвариант: `consumer_output + military_output == fotic_gdp` — коэффициенты держать синхронно.
2. **Синтаксис проверять по движку, не по памяти**: справочник `docs/hoi4-modding-skills-master` (дамп внутренней доки движка) + официальная вики. Эффектов `add_variable`, `add_timed_modifier`, `run = {...}`, глобального скоупа `global.` — **не существует**; ИИ-подсказки их регулярно выдумывают.
3. **GUI — только поэтапно**: один новый механизм за шаг, живой тест после каждого. Полный перенос 4 интерактивных кнопок одним махом уже приводил к воспроизводимому крашу движка (0xc0000409). После любой правки `.gui` — смотреть error.log на `Malformed token` **до** запроса теста.
4. **Спрайты и иконки проверять на существование** перед использованием (грепом по vanilla `interface/*.gfx`). У решений, категорий решений и идей — **три разных GFX-неймспейса** (`GFX_decision_*`, `GFX_decision_category_*`, `GFX_idea_*`) с разными наборами.
5. **Комментарии в `common/` и `events/` — только ASCII** (кириллица вычищается пайплайном). Кириллица безопасна в `localisation/*.yml` (строго UTF-8 with BOM) и `docs/`.
6. **Балансовые правки — сначала python-симуляция** пульса, потом код (папка scratchpad; примеры: калибровка валюты 0.02, потолок долгового штрафа 60).
7. **Тестовые прогоны — на чистом плейсете**: сторонние моды (русификатор, FPS Map) добавляют в error.log тысячи чужих строк; наши ошибки оценивать отдельно.
8. **on_startup перезапускается при каждой загрузке сейва** — любые неидемпотентные эффекты гейтить флагом.

## Сборка стим-версии
`mod\make_90x_steam_build.ps1` — робокопирует мод в `90x_steam`, исключая git, docs и дев-файлы, и генерирует дескрипторы. Папка билда зеркалируется с удалением — **всё нужное класть только в исходную `90x`** (включая thumbnail.png).

## Известные ограничения / дорожная карта
- **Чистка легаси**: мод собран поверх ванильных файлов, вычищено ~45k строк; в error.log остаётся ~1–2k наших строк (легаси scripted_effects удалённых стран, ванильные MIO/доктрины, ссылающиеся на замещённые фокусы/технологии, мёртвые спрайты DV_texticons). Список — в docs.
- **Экономика**: фаза B — событие вторжения в Кувейт с дипломатической вилкой СССР в СБ ООН, продажа золота, кредит ФРГ; фаза C — интеграция валюты и плана в кризисные решения, бюджет через law-слоты; фаза D — Китай/США.
- **Панель «Кремль»**: этапы 1–4 — переезд сводки, экономики и решений, вкладки в стиле TNO.
- **1992+**: терминальный флаг `fotic_sov_1992_started` зарезервирован; контента пока нет.
- Локализация только русская; EN отсутствует (кроме законов).
## Референсы
Millennium Dawn и TNO используются как **справочник практик** (структура scripted_gui, паттерн бюджета через law-слоты) — архитектура и масштаб не копируются. Всё заимствованное проверяется по документации движка перед использованием.
